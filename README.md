# הרפתקה בשדרה

אפליקציית ווב לסיור משפחתי מקוצר בשביל העצמאות בתל אביב: שבע תחנות לאורך שדרות רוטשילד, סיפור קצר בכל תחנה ומשימה משותפת לילדים, בלי ניקוד ובלי תחרות.

מסלול משפחתי מקוצר בשביל העצמאות: 7 עצירות מתוך 10 התחנות של השביל, **לא** המסלול הרשמי המלא. כל התחנות בחוץ, ומשך הפעילות (60–90 דקות) הוא אומדן שלנו ולא זמן רשמי. הפעילות ללא תשלום, חוץ מאוכל, חניה והוצאות אישיות.

- React + TypeScript + Vite, צד לקוח בלבד. אין שרת, מסד נתונים, התחברות או מפתחות API.
- ניתוב hash (`#/station/kiosk`), כך שאין צורך ב־server rewrites.
- התקדמות, שמות ותשובות נשמרים ב־`localStorage`. אם האחסון חסום (למשל גלישה פרטית), האפליקציה ממשיכה לעבוד בזיכרון ומציגה הודעה.
- manifest ו־service worker: אחרי טעינה ראשונה מוצלחת הממשק, הסיפורים והמשימות זמינים גם בלי אינטרנט. הניווט ב־Google Maps עדיין דורש חיבור.
- לא מבקשת גישה למיקום או למצלמה. אין קואורדינטות: הניווט נעשה דרך קישור Google Maps עם הכתובת כמחרוזת חיפוש.

## הרצה מקומית

דרוש Node.js 20 ומעלה (נבדק עם Node 22).

```bash
npm install
npm run dev          # שרת פיתוח, http://localhost:5173
```

ה־service worker נבנה רק ב־build, אז כדי לבדוק עבודה בלי אינטרנט:

```bash
npm run build
npm run serve:pages  # מגיש את dist תחת http://localhost:4173/independent-trail/
```

## בדיקות

```bash
npm test             # בדיקות יחידה (Vitest): לוגיקת התקדמות, אחסון, קישורי מפות, ניתוב, סיכום
npm run build        # בדיקת טיפוסים + build
npm run test:e2e     # בדיקות קצה לקצה (Playwright) על ה־build, ברוחב 375px, תחת נתיב repository
```

לבדיקות הקצה צריך דפדפן Chromium של Playwright (`npx playwright install chromium`), או להפנות לדפדפן קיים:

```bash
CHROMIUM_PATH=/path/to/chrome npm run test:e2e
```

## פרסום ב־GitHub Pages

1. דחפו את הקוד ל־branch `main` ב־GitHub.
2. ב־repository: **Settings → Pages → Build and deployment → Source** בחרו **GitHub Actions**.
3. כל push ל־`main` מריץ את `.github/workflows/deploy.yml`: התקנה, בדיקות יחידה, build ופרסום. אפשר גם להריץ ידנית מלשונית Actions.
4. הכתובת תהיה `https://<user>.github.io/<repo>/`.

ה־build משתמש ב־`base: './'`, כלומר כל הנכסים, ה־manifest וה־service worker נטענים בנתיב יחסי. לכן אותו build עובד גם תחת `/<repo>/` וגם בשורש דומיין, בלי לשנות הגדרות. אם בכל זאת צריך base מוחלט: `BASE_PATH=/my-repo/ npm run build`.

### התקנה באייפון

פותחים את הכתובת ב־Safari, משאירים את הדף פתוח כמה שניות (כדי שהכול יישמר), ואז שיתוף → "הוספה למסך הבית". כדאי לעשות את זה לפני היציאה, כשיש Wi‑Fi.

## מבנה הפרויקט

```
src/
  content/                 תוכן המסלולים, מופרד מהממשק
    types.ts               מודל הנתונים (Route, Station, SiteStatus)
    independence-short.ts  המסלול הנוכחי
    index.ts               רשימת המסלולים
  lib/                     לוגיקה: התקדמות, אחסון, ניתוב, מפות, סיכום
  screens/                 פתיחה, תחנה, כל התחנות, סיום, על המסלול
  components/              כותרת, אייקונים, איור, רכיבים משותפים
  sw-template.js           תבנית ה־service worker (רשימת הקבצים נוצרת ב־build)
public/                    manifest ואייקונים
e2e/                       בדיקות Playwright ושרת שמדמה GitHub Pages
scripts/make-icons.mjs     יצירת אייקוני PNG מ־icon.svg
```

### הוספת מסלול

1. צרו קובץ חדש ב־`src/content/` שמייצא אובייקט `Route` (העתיקו את `independence-short.ts` כתבנית).
2. הוסיפו אותו למערך `routes` ב־`src/content/index.ts`.
3. ההתקדמות נשמרת לפי מזהה המסלול, כך שמסלולים לא דורסים זה את זה.

כרגע האפליקציה מציגה את `defaultRouteId`. בחירת מסלול במסך הפתיחה היא תוספת קטנה כשיהיה מסלול שני.

## מקורות ואימות מידע

תוכן המסלול (עובדות, כתובות, סיפורים ומשימות) לקוח מתדריך תוכן שנבדק ב־9 באוקטובר 2026. הסיפורים והמשימות נכתבו עבור הפעילות המשפחתית ואינם ציטוטים מהמקורות. האפליקציה לא מושכת מידע מהמקורות בזמן ריצה. הם מוצגים במסך "על המסלול" לקריאה נוספת:

- עיריית תל אביב־יפו, שביל העצמאות: https://www.tel-aviv.gov.il/Visitors/KnowTelAviv/Pages/IndependenceTrail.aspx
- יישומון שביל העצמאות, כולל כתובות התחנות: https://apps.apple.com/us/app/id1422469642
- אתר התיירות של תל אביב, מצב בית העצמאות: https://visit-tlv.co.il/בית-העצמאות/

סביבת הבנייה לא הייתה מחוברת לאתרים האלה, ולכן התוכן לא הושווה אליהם ישירות.

**מה לא אומת או עשוי להשתנות:**

- מצב היכל העצמאות ("סגור לשיפוצים") נכון לבדיקה מ־9.10.2026. הוא שמור בשדות נפרדים: `visitType: 'exterior'`, `siteStatus.status: 'closed_for_renovation'`, `siteStatus.lastChecked: '2026-10-09'`. ההודעה בתחנה נבנית מהשדות האלה.
- לא אומת שהתצוגות במגדל שלום פתוחות בשבת, ולכן התחנה מתוכננת מבחוץ.
- שעות הפתיחה של שלוש התחנות שלא נכללו (בית הכנסת הגדול, מוזיאון ההגנה, מרכז המבקרים של בנק ישראל) והאפשרות לבקר בהן בשבת לא אומתו. הן מוצגות להקשר בלבד.
- אין הבטחה שהמזרקה פועלת, שסימון השביל רציף או שיש גישה לחזית של כל אתר. אפשר לדלג על כל תחנה.
- אין הוראות הליכה מפורטות בין התחנות. הפעילות מתחילה במפגש רחוב הרצל ושדרות רוטשילד, ומשם הניווט נעשה דרך כפתור "ניווט בהליכה".
- אין קואורדינטות. קישורי המפות בנויים משם התחנה והכתובת (למשל "הקיוסק הראשון, שדרות רוטשילד פינת הרצל, תל אביב"). כדאי לפתוח כל קישור פעם אחת לפני הסיור ולוודא ש־Google Maps מזהה את המקום.

### עדכון סטטוס של אתר

ב־`src/content/independence-short.ts` מעדכנים את `siteStatus.status` ואת `siteStatus.lastChecked`. אם האתר נפתח, אפשר למחוק את `siteStatus`, ואם מתכננים להיכנס, משנים את `visitType`. מעדכנים גם את `about.contentCheckedOn`.

## מה נבדק

- `tsc` ו־`vite build` עוברים בלי שגיאות או אזהרות.
- 14 בדיקות יחידה (Vitest): סדר התחנות, הפרדת סוג ביקור, סטטוס ותאריך, נוסח ההודעה בהיכל העצמאות, מחרוזות חיפוש למפות, אורך הסיפורים, קידוד עברית בקישורי מפות, מעבר לתחנה הבאה כולל חזרה לתחנות שדולגו, החלפת תפקידים, עמידות לנתונים פגומים ב־localStorage, נפילה לזיכרון כש־localStorage זורק שגיאה, ניתוב וסיכום.
- 7 בדיקות קצה לקצה (Playwright, Chromium, 375×667, מצב מובייל), על ה־build המוגש תחת `/independent-trail/`:
  - `lang="he"`, `dir="rtl"`, ואין גלילה אופקית במסכי פתיחה, תחנה, תחנות, סיום ומידע.
  - כל הכפתורים והקישורים הראשיים לפחות 44×44 פיקסלים.
  - זרימה מלאה: שינוי שם, התחלה, החלפת תפקידים, רמז והסבר נפתחים רק לפי בקשה, כתיבת תשובה, סיום תחנה, דילוג, רענון ושחזור, המשך מהמסך הראשי, רשימת סטטוסים, חזרה לתחנה שדולגה, השלמת כל התחנות, בחירת תחנה אהובה ושמירתה אחרי רענון, הורדת סיכום ובדיקת תוכנו, איפוס עם ביטול ואז עם אישור.
  - קישורי הניווט: `google.com/maps/dir/?api=1&travelmode=walking` עם יעד בעברית מקודד נכון.
  - כל הבקשות נשארות תחת נתיב ה־repository.
  - אחרי ביקור ראשון, במצב offline: טעינה מחדש עובדת, אפשר להתחיל ולפתוח תחנות, ומוצגת הודעה שהמפות דורשות חיבור.
  - כש־localStorage חסום: מוצגת הודעה והאפליקציה ממשיכה לעבוד.
  - `prefers-reduced-motion` מבטל מעברים.

**לא נבדק:** Safari אמיתי באייפון (WebKit לא היה זמין בסביבה). העיצוב משתמש ב־`100dvh`, `env(safe-area-inset-*)`, גופן 17px ומעלה בשדות (מונע זום אוטומטי ב־iOS) וקישורי הורדה מסוג Blob שנתמכים ב־iOS 13 ומעלה, אבל מומלץ לעבור על המסלול פעם אחת באייפון לפני היציאה.
