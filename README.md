# הרפתקה בשדרה

אפליקציית ווב לסיור מקוצר בשביל העצמאות בתל אביב, לכל הרכב: אדם אחד, משפחה או קבוצה גדולה. היא בנויה סביב סיפור המסגרת **״איך בונים עיר?״**: הקבוצה מתכננת עיר חדשה. בכל אחת משבע התחנות מגלים משהו על התפתחות תל אביב ומשלימים חלק ב״תוכנית העיר המשפחתית״, ובסוף מקבלים כרטיס ״העיר שלנו״ להורדה. המשחק בדיוני בהשראת ההיסטוריה, וההחלטות במשחק אינן מוצגות כאירועים היסטוריים.

מסלול משפחתי מקוצר בשביל העצמאות: 7 עצירות מתוך 10 התחנות של השביל, **לא** המסלול הרשמי המלא. כל התחנות בחוץ. משך הפעילות הוא אומדן שלנו ולא זמן רשמי: כ־60–90 דקות ברמה קלילה, כ־90–120 דקות ברמה רגילה, ויותר ברמה מאתגרת. הפעילות ללא תשלום, חוץ מאוכל, חניה והוצאות אישיות.

### מה יש בכל תחנה

- **הסיפור בקצרה** (עובדות, 30–45 שניות קריאה) ו**רוצים לדעת יותר?** (נפתח בלחיצה, עם סימון ״פרשנות״ / ״שימו לב״ לפסקאות שאינן עובדות).
- **המשימה שלנו**: 2–3 שלבים שנפתחים בהדרגה. סוגי שלבים: התבוננות (עם ״לא מצאנו״ וחלופה כשהאתר לא נגיש), ״ראינו / אנחנו חושבים״, תקציב שלא מאפשר חריגה, בחירת כרטיסים, מיון לקטגוריות, סידור עם כפתורי למעלה/למטה, התאמת משפחות למגרשים, הגרלה אקראית מקומית והשוואה, ו״מגילת העיר״ שמתמלאת מההחלטות הקודמות.
- במשימות סגורות: שני רמזים מדורגים, ופתרון רק אחרי לחיצה מפורשת. במשימות פתוחות: ״דוגמה למחשבה״ בלי ציון.
- **דילמת בונוס** אופציונלית (ברמה המאתגרת).
- בכל שלב אפשר לסמן ״ענינו בעל פה״ במקום להקליד. שאלות לדיון מוצגות כרשימה, ושדות כתיבה נפתחים רק אם רוצים.

### משתתפים, תפקידים ורמות

- **משתתפים:** במסך הפתיחה (ובמסך ״המשתתפים״ גם באמצע) מוסיפים ומסירים משתתפים, עם לפחות אחד. לכל משתתף יש שם וגיל לא חובה. ברירת המחדל היא שלושה משתתפים בלי שמות, ושם ריק מוצג כ״משתתף/ת 1״ וכן הלאה. לכל משתתף מזהה קבוע שלא תלוי בשם או במיקום ברשימה.
- **שינוי הרכב באמצע:** הסרת משתתף לא מוחקת תשובות או החלטות. התשובות שייכות לקבוצה או לצוות, לא לאדם. חלוקת התפקידים מתעדכנת להמשך.
- **תפקידים:** ניווט, הקראה, חיפוש בשטח, תיעוד והצגת החלטה. האפליקציה מציעה חלוקה אוטומטית, ואפשר להחליף או לשנות ידנית לכל תחנה:
  - משתתף אחד: בלי תפקידים, וניסוח אישי (״המשימה שלי״, ״עניתי בעל פה״, ״העיר שלי״).
  - שניים: כל אחד מקבל כמה תפקידים, ומתחלפים בתחנה הבאה.
  - שלושה עד חמישה: התפקידים מתחלקים ומתחלפים בכל תחנה.
  - שישה ומעלה: קבוצה אחת (חמישה תפקידים, ושאר הקבוצה מצטרפים כרצונם) או צוותים של 2–4. הניווט, התפקיד המוביל, עובר לאורך המסלול בין אנשים שונים.
- **צוותים:** כל הצוותים עובדים על אותו מכשיר. בוחרים ״הצוות שעונה עכשיו״, וכל צוות שומר החלטות משלו. בסיום יש כרטיס עיר לכל צוות והשוואה בין ההצעות, בלי מנצחים. אין סנכרון בין מכשירים.
- **המשימות לא תלויות במספר המשתתפים:**
  - שלוש המשפחות והמגרשים נפתרות יחד.
  - שלוש העמדות בוועדת התכנון הן כרטיסי נקודת מבט.
  - במשימות התבוננות מחפשים 2–3 פרטים בסך הכול.
  - בדיון כל אחד יכול להציע, ונשמרת החלטה משותפת אחת.
  - התקציבים קבועים ולא מוכפלים לפי מספר המשתתפים.
- **רמות:** קלילה, רגילה או מאתגרת, בבחירה מפורשת. הגילים רק מציעים רמה ולא קובעים אותה, והכול עובד גם בלי גילים. אפשר להחליף רמה בכל תחנה.
  - קלילה: מסתירה שלבים שמסומנים `advanced`, ומציגה מראש דוגמאות ורמז ראשון.
  - רגילה: כל השלבים.
  - מאתגרת: ההרחבות פתוחות, ויש דילמות בונוס.

- React + TypeScript + Vite, צד לקוח בלבד. אין שרת, מסד נתונים, התחברות או מפתחות API.
- ניתוב hash (`#/station/kiosk`), כך שאין צורך ב־server rewrites.
- התקדמות, שמות ותשובות נשמרים ב־`localStorage`. אם האחסון חסום (למשל גלישה פרטית), האפליקציה ממשיכה לעבוד בזיכרון ומציגה הודעה.
- manifest ו־service worker: אחרי טעינה ראשונה מוצלחת הממשק, הסיפורים והמשימות זמינים גם בלי אינטרנט. הניווט ב־Google Maps עדיין דורש חיבור.
- לא מבקשת גישה למיקום או למצלמה. אין קואורדינטות: הניווט נעשה דרך קישור Google Maps עם הכתובת כמחרוזת חיפוש.

## הרצה מקומית

דרוש Node.js 20 ומעלה (נבדק עם Node 22).

```bash
npm install
npm run dev          # שרת פיתוח, http://localhost:5173
```

ה־service worker נבנה רק ב־build, אז כדי לבדוק עבודה בלי אינטרנט:

```bash
npm run build
npm run serve:pages  # מגיש את dist תחת http://localhost:4173/independent-trail/
```

## בדיקות

```bash
npm test             # בדיקות יחידה (Vitest): לוגיקת התקדמות, אחסון, קישורי מפות, ניתוב, סיכום
npm run build        # בדיקת טיפוסים + build
npm run test:e2e     # בדיקות קצה לקצה (Playwright) על ה־build, ברוחב 375px, תחת נתיב repository
```

לבדיקות הקצה צריך דפדפן Chromium של Playwright (`npx playwright install chromium`), או להפנות לדפדפן קיים:

```bash
CHROMIUM_PATH=/path/to/chrome npm run test:e2e
```

## פרסום ב־GitHub Pages

1. דחפו את הקוד ל־branch `main` ב־GitHub.
2. ב־repository: **Settings → Pages → Build and deployment → Source** בחרו **GitHub Actions**.
3. כל push ל־`main` מריץ את `.github/workflows/deploy.yml`: בדיקות יחידה, build, ובמקביל בדיקות הקצה לקצה ב־Chromium. הפרסום קורה רק אם כולן עוברות. ב־Pull Request רצות אותן בדיקות בלי פרסום. אפשר גם להריץ ידנית מלשונית Actions.
4. הכתובת תהיה `https://<user>.github.io/<repo>/`.

ה־build משתמש ב־`base: './'`, כלומר כל הנכסים, ה־manifest וה־service worker נטענים בנתיב יחסי. לכן אותו build עובד גם תחת `/<repo>/` וגם בשורש דומיין, בלי לשנות הגדרות. אם בכל זאת צריך base מוחלט: `BASE_PATH=/my-repo/ npm run build`.

### התקנה באייפון

פותחים את הכתובת ב־Safari, משאירים את הדף פתוח כמה שניות (כדי שהכול יישמר), ואז שיתוף → "הוספה למסך הבית". כדאי לעשות את זה לפני היציאה, כשיש Wi‑Fi.

### הוספת מסלול

1. צרו קובץ חדש ב־`src/content/` שמייצא אובייקט `Route` (העתיקו את `independence-short.ts` כתבנית).
2. הוסיפו אותו למערך `routes` ב־`src/content/index.ts`.
3. ההתקדמות נשמרת לפי מזהה המסלול, כך שמסלולים לא דורסים זה את זה.
4. מזהי שלבים (`id`) חייבים להיות ייחודיים בכל המסלול, כי התשובות נשמרות לפיהם. בדיקות היחידה מוודאות את זה ואת ההפניות בין שלבים (`startFrom`, `from`).

חשוב לשמור על ההפרדה: עובדות היסטוריות רק ב־`story` ובפסקאות `fact`; פרשנות ושאלות קריאה בפסקאות `interpretation` / `note`; כל מה שבתוך `mission` הוא משחק בדיוני (עלויות, משפחות, מגרשים).

כרגע האפליקציה מציגה את `defaultRouteId`. בחירת מסלול במסך הפתיחה היא תוספת קטנה כשיהיה מסלול שני.

## מקורות ואימות מידע

תוכן המסלול (עובדות, כתובות, סיפורים ומשימות) לקוח מתדריך תוכן שנבדק ב־9 באוקטובר 2026. הסיפורים והמשימות נכתבו עבור הפעילות המשפחתית ואינם ציטוטים מהמקורות. האפליקציה לא מושכת מידע מהמקורות בזמן ריצה. הם מוצגים במסך "על המסלול" לקריאה נוספת:

- עיריית תל אביב־יפו: שביל העצמאות (https://www.tel-aviv.gov.il/Visitors/KnowTelAviv/Pages/IndependenceTrail.aspx)
- משרד החינוך: מעמד הגרלת הצדפים לאחוזת בית
- הספרייה הלאומית: תולדות הגימנסיה הרצליה והריסת המבנה
- אתר אבני מורשת: מזרקת נחום גוטמן
- ארכיון המדינה: מגילת העצמאות
- Visit TLV: מצב היכל העצמאות (https://visit-tlv.co.il/בית-העצמאות/)

למקורות בלי כתובת לא נוספה כתובת, כדי לא לנחש קישורים. הם מוצגים כטקסט בלבד.

סביבת הבנייה לא הייתה מחוברת לאתרים האלה, ולכן התוכן לא הושווה אליהם ישירות.

**מה לא אומת או עשוי להשתנות:**

- מצב היכל העצמאות ("סגור לשיפוצים", לא מתוכננת כניסה) נכון לבדיקה מ־9.10.2026. הוא שמור בשדות נפרדים: `visitType: 'exterior'`, `siteStatus.status: 'closed_for_renovation'`, `siteStatus.lastChecked: '2026-10-09'`. ההודעה בתחנה נבנית מהשדות האלה.
- לא אומת שהתצוגות במגדל שלום פתוחות בשבת, ולכן התחנה מתוכננת מבחוץ.
- שעות הפתיחה של שלוש התחנות שלא נכללו (בית הכנסת הגדול, מוזיאון ההגנה, מרכז המבקרים של בנק ישראל) והאפשרות לבקר בהן בשבת לא אומתו. הן מוצגות להקשר בלבד.
- אין הבטחה שהמזרקה פועלת, שסימון השביל רציף או שיש גישה לחזית של כל אתר. אפשר לדלג על כל תחנה.
- אין הוראות הליכה מפורטות בין התחנות. הפעילות מתחילה במפגש רחוב הרצל ושדרות רוטשילד, ומשם הניווט נעשה דרך כפתור "ניווט בהליכה".
- אין קואורדינטות. קישורי המפות בנויים משם התחנה והכתובת (למשל "הקיוסק הראשון, שדרות רוטשילד פינת הרצל, תל אביב"). כדאי לפתוח כל קישור פעם אחת לפני הסיור ולוודא ש־Google Maps מזהה את המקום.

### עדכון סטטוס של אתר

ב־`src/content/independence-short.ts` מעדכנים את `siteStatus.status` ואת `siteStatus.lastChecked`. אם האתר נפתח, אפשר למחוק את `siteStatus`, ואם מתכננים להיכנס, משנים את `visitType`. מעדכנים גם את `about.contentCheckedOn`.

    - כרטיס ״העיר שלנו״, הורדת קובץ ובדיקת תוכנו, ואיפוס עם אישור.
  - הרמה הקלילה מציגה פחות שלבים ויותר הסברים.
  - אין גלילה אופקית, וכל הכפתורים, הכרטיסים וכפתורי הסידור לפחות 44×44.
  - קישורי Google Maps בעברית מקודדת, וכל הבקשות תחת נתיב ה־repository.
  - עבודה במצב offline אחרי ביקור ראשון, localStorage חסום ו־`prefers-reduced-motion`.

**לא נבדק:** Safari אמיתי באייפון (WebKit לא היה זמין בסביבה). העיצוב משתמש ב־`100dvh`, `env(safe-area-inset-*)`, גופן 17px ומעלה בשדות (מונע זום אוטומטי ב־iOS) וקישורי הורדה מסוג Blob שנתמכים ב־iOS 13 ומעלה, אבל מומלץ לעבור על המסלול פעם אחת באייפון לפני היציאה.
